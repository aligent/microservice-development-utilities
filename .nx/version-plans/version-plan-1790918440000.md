- Added `APIGatewayService` (REST APIs, v1) with read-only `getRestApis`, `getResources`, `getApiKeys` and `getApiKey`.
- Added `APIGatewayV2Service` (HTTP and WebSocket APIs, v2) with read-only `getApis`, `getRoutes` and `getRoute`.
- `getApiKeys` and `getApiKey` always return API key values (`includeValue(s)` is baked in, no opt-out).
