MI-331: Major bump with improvements for `@aligent/microservice-util-lib`

### microservice-util-lib (major)

- Removed previously deprecated packages (`fetchSsmParams`, `retryMiddleware`, `retryWrapper`, `S3Dao`).
- Replaced `oauth-sign` dependency with a native OAuth 1.0a signing implementation
- Improved log middleware with a `Logger` interface and configurable log levels
- Added `retryMiddleware` for openapi-fetch clients
- Added `fetchSsmParams` and `S3Dao` utilities
- Dual-publish as CJS + ESM using `@nx/rollup`
- Fixed a circular dependency issue in authentication middlewares

### nx-openapi (patch)

- Aligned client template with the updated log middleware API
