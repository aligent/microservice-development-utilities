MI-331: Major bump with improvements for `@aligent/microservice-util-lib`

### microservice-util-lib (major)

- Removed previously deprecated utilities (`fetchSsmParams`, `retryMiddleware`, `S3Dao`) and their AWS SDK dependencies.
- Replaced the custom `Logger` interface with Powertools `LoggerInterface` (now a peer dependency).
- Removed the generated documents from `packages/microservice-util-lib/docs`. The pipeline will generate and publish them.
- Dual-publish as CJS + ESM using `@nx/rollup`.
- Fixed a circular dependency issue in authentication middlewares.

### aws-wrappers (patch)

- Fixed `package-dist` target to depend on `typedoc`, ensuring generated docs are present in `dist/`
- Removed the generated documents from `packages/aws-wrappers/docs`. The pipeline will generate and publish them.

### nx-openapi (patch)

- Aligned client template with the updated log middleware API
