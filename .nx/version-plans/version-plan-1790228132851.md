---
nx-openapi: minor
---

- Generated client (`client.ts.template`) now wraps the client in `createErrorThrowingClient`
  (`ErrorThrowingClient<paths>`), adds a `private readonly logger` property, and logs retries via
  `retryFetch`'s `onRetry` callback instead of passing `options.fetch` straight through.
- Auth middleware (`--authMethod`) is now registered as an argument of the single
  `this.client.use(...)` call, right after `throwOnNotOk()`, instead of being inserted as a
  separate `use()` statement.
- Simplified the generated auth middleware config: `api-key` no longer fetches credentials from
  SSM Parameter Store (dropped `fetchSsmParams`, the cached `credential` class property, and the
  `credentialPath` constructor parameter) — every auth method now scaffolds placeholder config for
  you to fill in, with `oauth2.0` extracting a `fetchAccessToken()` stub above the class.
- Removed `baseUrl` from the generated client's `tsconfig.json.template` and marked the clients
  barrel `index.ts.template` with `eslint-disable no-barrel-files/no-barrel-files`.
