MI-331: Re-release the 0.5.11 changes as 0.6.0. No code changes since 0.5.11.

0.5.11 contained breaking changes but was published as a patch: Nx downgraded the planned `minor` bump to `patch` for the `0.x` version. Release tooling now applies the planned bump as written. Upgrade to 0.6.0 instead of 0.5.11.

Breaking changes carried from 0.5.11:

- **Node 20 or later is now required** (`engines.node` was `>=18`).
- **`DynamoDBService.batchGet` and `batchWrite` throw a `BatchOperationError`** instead of a plain `Error` when items remain unprocessed after the final attempt. Callers that matched the old message must match on the error `name`.

See the 0.5.11 release notes for the full list of fixes.
