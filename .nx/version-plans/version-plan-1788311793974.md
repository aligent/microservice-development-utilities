Fix #245: `tsconfig.lib.json` overrides `module: ESNext` without an explicit `target`, dropping the `target: es2022` implied by the inherited `module: Node16` and falling back to TypeScript's ES5 default. Set `target: "ES2022"` explicitly so the package's own compiled output (`dist/`) emits native classes/`async`/`await` instead of `tslib`-downlevelled code.

No runtime or correctness impact for consumers — `vite-plugin-handler` is a build-time-only Vite plugin, so it never ships into a Lambda bundle. The cost was purely wasted emit (ES5 IIFE-wrapped classes, `tslib` `__awaiter`/`__generator` helpers) on a package that only ever runs under Node 20+.

This release also includes the workspace's migration from npm to Yarn Berry as the package manager (Corepack-pinned, `nodeLinker: node-modules`). This is an internal tooling and CI change only — it does not alter this package's public API, runtime behaviour, or published output. The other packages in this release are bumped solely to reflect that migration.

Also includes the Nx 22.7.6 → 23.1.2 workspace upgrade (`nx` and the `@nx/*` plugin devDependencies). Internal build-tooling change only — devDependency versions and generator-internal tsconfig/rollup config only, no `dist/` output changes (verified via `yarn build:all` before and after).
