MI-331: Add `SESService` to `aws-wrappers`, and fix the `nx-cdk` preset templates and pre-commit hook.

**aws-wrappers** (MI-331): Add `SESService`, a wrapper around the SES v2 client with `sendEmail` and `sendBulkEmail`.

`sendBulkEmail` auto-chunks entries to the 50-entry SES limit and throws a `BatchOperationError` after every chunk is sent if any entry is not `SUCCESS`. Recipient addresses, subjects, bodies and template data are never logged at INFO.

**nx-cdk** (MI-331): Fix the preset templates so a freshly generated workspace passes `cdk synth`, lint and type-checking.

Existing workspaces need the same edits applied by hand:

- `application/bin/main.ts`: pass the stage name with `new MicroserviceChecks({ stageName })` (synth throws without it), import `AspectOptions` and `IAspect` with the `type` modifier, and declare `let duration: 'SHORT' | 'MEDIUM' | 'LONG';` without an initialiser.
- `application/lib/service-stacks.ts`: build the stage `env` with `...(process.env.CDK_DEFAULT_ACCOUNT && { account: process.env.CDK_DEFAULT_ACCOUNT })` so an unset account is omitted under `exactOptionalPropertyTypes`.
- `libs/infra/tsconfig.json`: remove the `baseUrl` option, which TypeScript 6 rejects.
- `README.md`: list `vite.config.base.mjs` in the project structure instead of `rolldown.config.base.mjs` and `vitest.config.base.mjs`.

**nx-cdk** (MI-331): Fix the generated workspace pre-commit hook so it works on macOS. BSD `paste` requires an explicit stdin operand, so the hook silently skipped lint, type-check and tests on macOS.

Existing workspaces need the same edit applied by hand: in `.git-hooks/pre-commit`, change `paste -sd,` to `paste -sd, -`.
